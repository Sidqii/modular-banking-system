# Modular Banking System PHP

Learning OOP the hard way with pure PHP 🗿

This project started as:
"lemme just learn abstract and interface real quick"

Then suddenly:
- encapsulation started protecting bank balances from financial crimes
- interfaces became plug & play superpowers
- traits turned into reusable copy-paste prevention technology
- business rules started attacking my math skills
- modular design somehow began making sense

Now I'm here...
building a tiny banking system to suffer less in future backend projects 😭

## Lessons Learned

- State lives as long as the object lives
- `foreach ($array as $value)` is not the same as `foreach ($array as $index => $value)`
- CurrentUser nearly made me cry
- Updating balance requires knowing where the balance actually lives
- Business logic is harder than syntax
- OOP starts making sense when duplication becomes painful
